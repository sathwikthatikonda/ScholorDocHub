ScholarDocHub

A smart scholarship discovery and eligibility platform that helps students find scholarships based on their academic profile, demographics, and financial background.

🚀 Features
🎓 Academic-based scholarship matching
🌍 Demographic eligibility filtering
💰 Financial need analysis
📄 Multi-step scholarship application form
🔍 Personalized scholarship recommendations
📱 Responsive and modern UI
